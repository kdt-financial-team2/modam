3. 테스트 공통 기술 스택 및 패턴
--------------------------------------------------------------------------------

  인증 방식:
    - formLogin() + MockHttpSession으로 Spring Security 세션 기반 인증
    - .session(session) 으로 인증된 요청 전달

  GlobalExceptionHandler 예외 → HTTP 상태 코드 매핑 (핵심):
    - MethodArgumentNotValidException (@Valid 실패)  → 400 BAD_REQUEST
    - IllegalArgumentException                       → 400 BAD_REQUEST
    - IllegalStateException                          → 409 CONFLICT
    - NPE (null 체크 없는 @AuthenticationPrincipal)  → MockMvc가 ServletException으로
                                                       전파 → assertThrows 필요

  비로그인 테스트 패턴 2가지:
    [패턴 A] 컨트롤러에 null 체크 있음 → IllegalStateException → 409
      .andExpect(status().isConflict())

    [패턴 B] 컨트롤러에 null 체크 없음 → NPE → MockMvc re-throw
      assertThrows(Exception.class, () ->
          mockMvc.perform(...).andReturn()
      );

  Security 설정: anyRequest().permitAll()
    → @AuthenticationPrincipal 없는 엔드포인트는 비로그인 시 200 반환

7. 주요 교훈 및 참고사항
--------------------------------------------------------------------------------

  [예외 처리 매핑]
  - GlobalExceptionHandler는 IllegalStateException을 409로 처리함
    (개발자들이 5xx로 착각하기 쉬움 — 실제로는 409 CONFLICT)
  - NPE는 GlobalExceptionHandler가 잡지 못하고 MockMvc가 직접 throw함
    → andExpect()로 상태 코드 확인 불가, assertThrows() 패턴 필수

  [Security]
  - anyRequest().permitAll() 설정으로 인증 없이 대부분 접근 가능
  - 비로그인 시 동작은 @AuthenticationPrincipal 처리 방식에 따라 다름:
      null 체크 O → 409 CONFLICT
      null 체크 X → NPE → assertThrows

  [TransactionService 의존성]
  - createTransaction() 내부에서 AccountMember(ACCEPT) 존재 여부를 검증함
  - 저축 납입, 카드 결제 등 TransactionService를 거치는 모든 작업에서
    AccountMember 미등록 시 IllegalArgumentException 발생

  [Oracle DB 호환성]
  - MySQL 전용 함수 YEAR(), MONTH() 는 Oracle에서 사용 불가
  - Oracle에서는 EXTRACT(YEAR FROM col), EXTRACT(MONTH FROM col) 사용 권장
  - native query (nativeQuery = true) 작성 시 DB 벤더 고려 필요

  [DTO 검증 어노테이션]
  - @Valid 없이 @RequestBody 로만 받으면 DTO 내 @Size, @NotBlank 등 무시됨
  - AccountCreateRequestDto.agreeFinance: @AssertTrue 필수 필드
    → 테스트에서 명시적으로 true 설정 필요
